# Examples

- `quickstart.py`: fastest complete fit with built-in nuisance models.
- `synthetic_1d.py`: longer scalar synthetic example.
- `custom_nuisances.py`: supplying your own fitted propensity and outcome sampler.
- `image_api.py`: tiny image/U-Net + EOT API smoke example (not a benchmark).
- `demo.ipynb`: notebook version of the quick start.
